# HaqDesk AI — Complete Low-Fidelity Wireframe Set

This Figma Make / React project contains the original HaqDesk AI UI Design System plus a complete desktop-first low-fidelity wireframe set for the FYP Chapter 4.4 Interface Design section.

## Design rules

- Desktop-first 1440×900 academic wireframes
- Greyscale only for low-fidelity screens
- No gradients, branding colours, decorative imagery, or high-fidelity visual polish in the wireframes
- Structure follows the audited current HaqDesk AI frontend
- FYP demonstration channels shown as Facebook Messenger, Instagram Direct, and Gmail/Email
- WhatsApp is not presented as an active FYP demonstration channel
- Existing Figma-generated WF-01 Login was retained
- All additional wireframes are implemented as separate navigable screens

## Navigation

From the Design System, click **15 Low-Fidelity Wireframes →**.

The wireframe gallery links to all 15 screens. Each individual wireframe includes fixed controls for:
- Design System
- All Wireframes
- Previous
- Next

## Main source files

- `src/App.tsx` — original design system plus wireframe navigation

- `src/WireframeScreens.tsx` — WF-02 through WF-15 and wireframe gallery
- `src/index.css` — global styling
